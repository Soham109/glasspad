# Support

Glasspad is free and made by one person, Soham Aggarwal. Help is best effort.

| You want to | Go to |
| --- | --- |
| Install it, or fix a failed step | [Install guide](https://glasspad.sohamaggarwal.com/install) |
| Learn a mode or fix a common problem | [Guide](https://glasspad.sohamaggarwal.com/guide) |
| Report a bug or ask for a feature | [New issue](https://github.com/Soham109/glasspad/issues/new/choose) |
| Ask a question | Email hello@sohamaggarwal.com |
| Report a security problem | [SECURITY.md](SECURITY.md), never a public issue |

When something breaks, include your Glasspad version (Settings > About on the Mac or the iPhone), your iPhone and iOS version, and your Mac and macOS version. For install or renewal problems, the logs are in `~/Library/Logs/Glasspad`.
