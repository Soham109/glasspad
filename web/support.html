How can I help?

Most answers are one click away. If yours is not, write to me. I read every message.

  • GuideHow to use every mode, Layouts, Actions and StandBy.
  • Install problemsThe installer, permissions, Developer Mode and uninstall.
  • Fix a problemThe pointer does not move, the iPhone cannot find the Mac, and more.
  • Report a bugOpen a GitHub issue. Steps to reproduce help most.
  • Suggest an ideaAsk for a mode, a button or an app on GitHub.
  • Email mehello@sohamaggarwal.com, for anything else.

Quick fixes

ProblemFix
The pointer does not moveSystem Settings, Privacy & Security, Accessibility: switch Glasspad off and on.
The iPhone cannot find the MacSame Wi-Fi on both, and allow Local Network for Glasspad on the iPhone.
Media shows no songSystem Settings, Privacy & Security, Automation, Glasspad: switch on Spotify and Music.
The app stopped opening after a weekThe Mac could not renew it in time. How renewal works.
Developer Mode is missingPlug the iPhone in and run the install command once.

When you write, include

  • Glasspad version

    Settings, About, on the iPhone or the Mac.

  • macOS and iOS versions

    And which Mac and iPhone you use.

  • What happened

    What you did, what you expected, and a screenshot if you can.

Found a security problem? Please do not open a public issue. Follow SECURITY.md to report it privately.
